# UI/UX Guidance Sources

The user requested review of [nextlevelbuilder/ui-ux-pro-max-skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) before SalonFlow design refinements. Its beauty/spa/wellness guidance favors a calming, premium booking experience built with soft visual depth, a clear service menu, direct booking actions, and responsive accessibility. Its product dashboard guidance emphasizes functional hierarchy, status clarity, visible loading/error feedback, readable text, explicit input labels, and reduced-motion respect.

SalonFlow will retain its established **deep ink**, **ivory**, **terracotta**, and **jade** system rather than copy the repository's sample palette. This preserves the product's existing Georgian visual identity while applying the compatible recommendations: calm depth, clear hierarchy, purposeful micro-interactions, and accessible operational density.
