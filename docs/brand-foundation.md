# SalonFlow — Brand Foundation

## Positioning

SalonFlow is a **Georgian-first, warm, orderly, premium, and trustworthy operations platform** for service businesses. Its direct booking link and conflict-safe internal workspace are the core differentiation; it is not positioned as a generic marketplace or a visual copy of another salon product.[^brief]

| Foundation | SalonFlow expression |
| --- | --- |
| Purpose | Make daily salon operations and client booking clearer, safer, and easier to act on. |
| Promise | Every visible action should state what will happen, respect scope and schedule rules, and use understandable Georgian. |
| Values | Practical clarity, respectful service, operational integrity, and quiet confidence. |
| Personality | Warm but not casual, premium but not ornate, precise but not technical. |
| Voice | Georgian-first, direct, supportive, and specific about state or next action. |

## Visual and verbal rules

Use paper and ivory for calm reading surfaces, deep ink for hierarchy and navigation, terracotta for one primary action, jade for confirmed outcomes, and violet for secondary scheduling/focus emphasis. Status never relies on color alone. Use a Georgian-capable sans-serif for operational UI and retain readable system fallbacks.

| Do | Do not |
| --- | --- |
| Say what happens next: “დაჯავშნების ნახვა”, “სამუშაო სივრცის შექმნა”. | Use raw server errors, internal references, `local_` identifiers, or vague success claims. |
| Keep a clear, labelled primary action per surface. | Use generic blue-first dashboards, heavy glass effects, copied competitor styling, or decorative motion that slows operations. |
| Describe unconfigured delivery/payment features as unavailable. | Invent ratings, testimonials, staff/customer images, provider connections, or performance claims. |

## Brand protection

The repository must preserve SalonFlow naming, Georgian-first copy, token usage, and no-fabricated-review rule across public and protected surfaces. Any future logo, photograph, review, or social proof requires owner-supplied rights and evidence before publication.
