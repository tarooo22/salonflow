# SalonFlow — საჯარო სალონის პროფილის launch checklist

ეს checklist განკუთვნილია მფლობელისა და platform admin-ისთვის. იგი არ აქვეყნებს სალონს, არ ამატებს promotion-ს და არ ცვლის booking წესებს ავტომატურად.

| შემოწმება | პასუხისმგებელი | წარმატების პირობა |
|---|---|---|
| ფილიალის სახელი და მოკლე აღწერა | მფლობელი | ტექსტი ფაქტობრივია, ქართულად იკითხება და არ შეიცავს დაუდასტურებელ დაპირებას. |
| Cover ფოტო და აღწერა | მფლობელი | გამოყენებულია მხოლოდ რეალური, უფლებამოსილი ფოტო; ფოტო იტვირთება და აქვს მოკლე ქართული alt აღწერა. |
| Online booking | მფლობელი | ფილიალი booking-enabled-ია და აქვს მინიმუმ ერთი აქტიური online-bookable სერვისი. |
| Marketplace კატეგორია | მფლობელი | თითოეული კატეგორია მიბმულია რეალურ, აქტიურ ონლაინ სერვისზე. |
| რუკის გამოჩენა | მფლობელი | საჭიროების შემთხვევაში location point დადასტურებულია და map consent ცალსახად ჩართულია. |
| Review | platform admin | ადმინისტრატორი ამოწმებს listing-ს, media/public profile readiness-ს და მხოლოდ შემდეგ ამტკიცებს ან აბრუნებს მოკლე შენიშვნით. |
| Public smoke test | მფლობელი ან admin | Directory, profile და booking link იხსნება; არ ჩანს test content, broken image ან private მისამართი/ბილინგის მონაცემი. |

## აკრძალული პრაქტიკა

არ ატვირთოთ სხვა სალონის ფოტო, არ შექმნათ მოჩვენებითი შეფასება ან ხელოვნური რეიტინგი, არ განათავსოთ დაუდასტურებელი ფასი/availability და არ ჩართოთ რუკის გამოჩენა მფლობელის ცალსახა თანხმობის გარეშე.
