# Reference Notes for SalonFlow Handoff

## Purpose

The pages below were reviewed only as public UX references. Their screenshots are included in the handoff package so the origin of high-level inspiration is transparent. SalonFlow does not copy their source code, visual assets, client data, pricing, reviews, or branded presentation.

| Reference | URL | High-level UX observation | SalonFlow boundary |
|---|---|---|---|
| Visage | https://www.visage.ge/ | A Georgian salon-management SaaS public page with product-navigation, booking, calendar, CRM and analytics concepts. | Used only to benchmark information hierarchy and operational-product framing. |
| MySalon | https://www.mysalon.ge/ka | A Georgian salon-discovery marketplace with category browsing and salon cards. | Used only to benchmark discovery and booking-entry clarity. |
| Visage calendar demo | https://www.visage.ge/demo/calendar | A public demo showing a multi-staff calendar grid, appointment blocks and workspace navigation. | Used only to benchmark calendar scanability, action placement and desktop operational density. |
| Visage booking demo | https://www.visage.ge/demo/book | A public four-step salon booking demo with a service-first entry and booking progress. | Used only to benchmark booking orientation, selection clarity and public flow structure. |
| UI/UX Pro Max Skill | https://ui-ux-pro-max-skill.com/ | Public documentation for a design-intelligence skill used during design review. | Used only as non-binding guidance for accessibility, interaction and component consistency. |
| 21st | https://21st.dev/ | Public component registry consulted through its configured reference integration. | Used only for component/hierarchy inspiration; third-party component code was not imported into SalonFlow. |
